> **"Crafted with Obsession."**
> A high-performance, cinematic personal portfolio engineered to showcase technical depth and creative precision.

## ⚡ Overview

This is not just a portfolio; it is a **Digital Experience**. Built with **React** and **TypeScript**, it leverages **Framer Motion** for complex, physics-based animations and **Tailwind CSS** for a precision-engineered "Stealth Luxury" aesthetic.

The site features a custom **"Obsidian & Gold"** theme, blending high-end typographic editorial design with interactive, game-like UI elements.

## 🌟 Key Features

### 1. The "Command Center" Navigation
* **Liquid Gold Glider:** A magnetic, physics-based active state that follows the user's journey.
* **Intelligent Scroll Spy:** Uses a "Center-Viewport" detection engine to accurately highlight sections regardless of their height.
* **Glassmorphism:** High-index backdrop blur (`backdrop-blur-xl`) for a premium hardware feel.

### 2. The "Neural Pixel" Generator
* **Custom AI Visualizer:** For projects marked `in-progress` (like CashCheck AI), the site dynamically renders a "Neural Quantization" reactor—a living grid of scanning pixels—instead of a static image.
* **Live Status Indicators:** Pulsating heartbeat monitors for system status.

### 3. Cinematic Project Gallery
* **Slow-Motion Parallax:** Project images move at a different velocity than the scroll, creating deep 3D depth.
* **Smart Cropping:** Certificate images are automatically analyzed and centered to fit their glass containers perfectly.
* **Thick Glass UI:** Multi-layered box shadows and inset lighting effects to simulate physical glass blocks.

### 4. Technical Matrix (Skills)
* **Infinite Marquee:** A frictionless, auto-scrolling ticker of technical skills.
* **Quantum Grid:** Interactive skill chips that react to hover states with a "data-scan" animation.

## 🛠️ Tech Stack

* **Core:** React 18, TypeScript, Vite
* **Styling:** Tailwind CSS, CLSX, Tailwind Merge
* **Animation:** Framer Motion (Spring physics, Scroll-linked animations, Layout shifts)
* **Icons:** Lucide React
* **Deployment:** Netlify / Vercel

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher)
* npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/adityashindeorg/portfolio.git](https://github.com/adityashindeorg/portfolio.git)
    cd portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
